Дисциплина "Теория баз данных. Программирование MS SQL Server"
Репозиторий предназначен для хранения всех материалов, связанных с дисциплиной, включа ДЗ, практику и теоритические материалы.

Описание дисциплины
Изучение данной дисциплины направлено на освоение навыков работы с реляционными базами данных при помощи языка TSQL в среде MS SQL Server.

Содержимое
1.Домашние задания по дисциплине. Состоит из самого выполненного задания (задание.docx), фотоматериалов к заданию  и README файла, кратко объясняющего суть задания и изучаемой темы.
2.Теоретические материалы лекций.
3.Практические работы по основным темам курса, выполняемые на занятиях. Состоит из самого выполненного задания (практика.docx), фотоматериалов к заданию и README файла, кратко объясняющего суть задания и изучаемой темы.
4.Задания для контроля усвоенных знаний.
