КОНСПЕКТ

1. Основные понятия

Аутентификация — проверка данных пользователя для подтверждения его личности.

Авторизация — определение прав пользователя на работу с ресурсами системы после входа.

Структура SQL Server:

Компьютер - Экземпляр сервера -База данных -Таблицы -Данные.

2. Типы данных в базе данных

Битовые — хранят значения в виде битов.
Целочисленные — INT.
Дробные — REAL, FLOAT, DECIMAL.
Символьные — CHAR, VARCHAR, NVARCHAR. VARCHAR хранит символы в зависимости от используемой кодировки, а NVARCHAR поддерживает Unicode.
Дата и время — DATETIME, SMALLDATETIME.
Специальные — TEXT, BIT, IMAGE.
Денежные — MONEY.

3. Файлы базы данных

MDF — основной файл базы данных.
NDF — дополнительный файл данных.
LDF — файл журнала транзакций, в котором записываются изменения базы данных.

Файловые группы

Первичная файловая группа — содержит основной файл данных и может включать дополнительные файлы.
Вторичные файловые группы — используются для размещения дополнительных файлов данных.

4. Основные элементы базы данных

Таблицы — хранят данные в строках и столбцах.
Представления — показывают данные на основе запросов.
Хранимые процедуры — содержат команды, которые можно запускать повторно.
BLOB-поля — предназначены для хранения больших двоичных данных.
Метаданные — информация о структуре и свойствах базы данных.

5. Системные базы данных SQL Server

 master — хранит сведения о сервере, базах данных и настройках.
model — используется как образец при создании новых баз данных.
 msdb — содержит информацию о заданиях, резервном копировании и обслуживании.
 tempdb — предназначена для временных таблиц и других временных объектов.
 Resource — содержит системные объекты SQL Server.

6. Страницы и экстенты

Данные базы хранятся в файлах, которые разделены на страницы.
Страница — основная единица хранения данных в SQL Server. Её размер составляет 8 КБ. Она включает заголовок размером 96 байт, данные и таблицу смещений строк.

Экстент — область дискового пространства, состоящая из восьми последовательных страниц. Его размер составляет 64 КБ.

7. Установка и работа с SQL Server

Для работы используются SQL Server 2025 и SQL Server Management Studio (SSMS).

Основные этапы работы:

1. Установить SQL Server.
2. Подключиться к экземпляру сервера через SSMS.
3. Создать базу данных, при необходимости используя права администратора.
4. Создать таблицы.
5. Добавить записи в таблицы.

Пример создания таблицы:

USE [college];
GO
CREATE TABLE [dbo].[Users] (
    [Id] INT IDENTITY(1,1) PRIMARY KEY,
    [Login] NVARCHAR(50) NOT NULL UNIQUE,
    [Age] INT NOT NULL
);
GO

В таблице Users хранятся идентификатор, логин и возраст пользователя. IDENTITY автоматически увеличивает идентификатор, PRIMARY KEY задаёт первичный ключ, а UNIQUE запрещает повторение логина.

8. Уровни представления базы данных
Внешний уровень — представление данных для пользователей.
Логический уровень — описание структуры базы данных и связей между данными.
Физический уровень — организация хранения данных на носителях.

9. Основы языка T-SQL

Пакет — группа SQL-команд, которая отправляется серверу для обработки.

Переменные
DECLARE — объявление переменной.
 SET — присвоение значения переменной.
 SELECT — получение или присвоение значения.

Основные операторы и функции
PRINT — вывод текстового сообщения.
CAST — преобразование значения в другой тип данных.
ROUND — округление числа.
FLOOR — округление вниз.
POWER — возведение в степень.
LOG — вычисление логарифма.

Также используются арифметические операции, объединение строк, строковые функции и функции для работы с датой и временем.

10. Управляющие конструкции

BEGIN...END — объединение команд в один блок.
 IF...ELSE — выполнение команд в зависимости от условия.
 CASE...WHEN — выбор результата по условию.
 WHILE — повторение команд в цикле.
 TRY...CATCH — обработка ошибок.
 RAISERROR — формирование сообщения об ошибке.
 WAITFOR DELAY — ожидание заданного промежутка времени.
WAITFOR TIME — ожидание до указанного времени.

11. Курсоры

Курсор — механизм, который позволяет последовательно обрабатывать строки результата запроса по одной записи.

12. Программные объекты SQL Server

К основным программным объектам относятся:
 Хранимые процедуры — наборы SQL-команд для выполнения определённых задач.
Скалярные функции — возвращают одно значение.
 Табличные функции — возвращают таблицу с результатами.
 Триггеры — автоматически выполняют команды при наступлении определённых событий в базе данных.
