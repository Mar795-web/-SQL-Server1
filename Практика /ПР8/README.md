пр3.docx — триггеры

В документе описан следующий порядок работы с триггером на таблицу:

1. Создание триггера.
2. Проверка работы триггера.
3. Изменение триггера.
4. Проверка внесённых изменений.
5. Удаление триггера.

Требования и запуск

Для выполнения SQL-практик потребуется совместимая СУБД и среда
выполнения SQL-кода. Если работы рассчитаны на Microsoft SQL Server,
можно использовать SQL Server Management Studio (SSMS).

1. Откройте соответствующий SQL-файл или перенесите код из документа в
окно запроса.
2. Подключитесь к нужному серверу и выберите базу данных, для которой
выполняется работа.
3. Перед запуском проверьте условия задач, названия таблиц и наличие
необходимых объектов.
4. Выполните запросы по порядку и проверьте полученный результат.

 **Примечание:** загруженные документы в доступном текстовом содержимом
в основном содержат заголовки и этапы работ, но не полный SQL-код.
Поэтому README описывает только то, что можно подтвердить по самим
документам, и не добавляет вымышленные реализации.
