Документ с диаграммами и кодом

Файл диограммы и код (1).docx не содержит доступных примеров диаграмм
или кода — в нём записано, что дальнейшая работа не получилась из-за
ошибки. Поэтому конкретные диаграммы по этому файлу описать нельзя.

Требования

• Microsoft SQL Server;
• база данных BSTU с нужными таблицами и столбцами;
• SQL Server Management Studio (SSMS) или другая среда, поддерживающая
T-SQL.

Запуск SQL-примеров

1. Подготовьте базу данных BSTU.
2. Откройте SQL Server Management Studio и подключитесь к серверу.
3. Проверьте, что названия таблиц и столбцов совпадают с используемыми
в запросе.
4. Скопируйте нужный SQL-пример в окно запроса и выполните его.



Примечание: исходные материалы могут использовать разные названия
таблиц для дисциплин (`SUBJECT` и `SUBJECTGROUP`). Перед запуском
проверьте фактическую структуру своей базы данных.
