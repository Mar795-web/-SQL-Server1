Практическая работа: код для слайдов 8 и 14

В примерах используются таблицы и поля базы данных BSTU, в том числе:

• dbo.STUDENT — студенты;
• dbo.AUDITORIUM — аудитории;
• dbo.TEACHER — преподаватели;
• dbo.SUBJECT — дисциплины (название таблицы следует сверить со
схемой базы, поскольку в исходном коде также встречается обращение к
dbo.SUBJECTGROUP);
• поле PULPIT — кафедра.

Код демонстрирует, как получить количество студентов, аудиторий и
преподавателей, сгруппировать аудитории по типу, подсчитать дисциплины
по кафедрам, а также вычислить общую и среднюю вместимость аудиторий и
процент аудиторий с вместимостью выше средней.

Пример подсчёта аудиторий по типу:

USE BSTU;
GO

SELECT
    AUDITORIUM_TYPE AS [Тип аудитории],
    COUNT(*) AS [Количество аудиторий]
FROM dbo.AUDITORIUM
GROUP BY AUDITORIUM_TYPE;
GO

Пример расчёта вместимости аудиторий:

USE BSTU;
GO

SELECT
    SUM(AUDITORIUM_CAPACITY) AS [Общая вместимость],
    COUNT(*) AS [Количество аудиторий],
    AVG(AUDITORIUM_CAPACITY) AS [Средняя вместимость]
FROM dbo.AUDITORIUM;
GO
