Цель работы

Изучить работу транзакций, обработку ошибок и уровни изоляции в Microsoft SQL Server.

Задание 1. BEGIN, COMMIT и ROLLBACK

Создана таблица Accounts с полями AccountId, OwnerName и Balance.

Добавлены три счёта. Выполнен перевод 1000 рублей со счёта № 1 на счёт № 2.

BEGIN TRANSACTION — начало транзакции.
COMMIT — сохранение изменений.
ROLLBACK — отмена изменений при ошибке.

Задание 2. TRY…CATCH и XACT_ABORT

Реализована обработка ошибок при переводе денег между счетами.

В блоке CATCH используются ERROR_MESSAGE() и ERROR_NUMBER() для вывода информации об ошибке. Если транзакция активна, выполняется откат.

Режимы:

SET XACT_ABORT ON — при большинстве ошибок времени выполнения транзакция прерывается.
SET XACT_ABORT OFF — некоторые ошибки позволяют продолжить выполнение транзакции.

Задание 3. Вложенные транзакции и SAVE TRANSACTION

Создана таблица TransferLog для записи переводов.

Использованы три операции: списание со счёта A, зачисление на счёт B и запись в журнал переводов.

SAVE TRANSACTION SavePoint1 создаёт точку сохранения. Команда ROLLBACK TRANSACTION SavePoint1 позволяет отменить изменения после этой точки, не отменяя всю транзакцию.

Откат к точке сохранения не уменьшает @@TRANCOUNT, потому что он не завершает транзакцию.
