Что изучалось
На занятии были рассмотрены основы работы с индексами в MS SQL Server: сбор статистики выполнения запросов (I/O и время), создание кластерных и некластерных индексов, использование покрывающих индексов (Covering Index) с директивой INCLUDE, а также анализ влияния индексов на скорость операций чтения и записи.
Суть задания
Выполнить практические задания по работе с индексами в T-SQL:
Сбор статистики запроса — включить SET STATISTICS IO ON и SET STATISTICS TIME ON, выполнить поиск по Email без индекса и проанализировать статистику: сканирование таблицы вместо поиска, 7143 логических чтения (~57 МБ), 0 физических чтений (данные в кэше).
Кластерный индекс — создать кластерный индекс по CustomerID через CREATE CLUSTERED INDEX, проверить его наличие через sp_helpindex, протестировать точечный поиск (Index Seek) и поиск по диапазону (Index Range Scan).
Некластерный индекс — создать некластерный индекс по Email с INCLUDE (LastName) как покрывающий индекс, а также индекс по City. Сравнить эффективность поиска по Email до и после создания индекса.
