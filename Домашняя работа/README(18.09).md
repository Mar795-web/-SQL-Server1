SQL Server — Функция и хранимая процедура

Цель работы

Создать пользовательскую функцию и хранимую процедуру в SQL Server.

1. Функция

Функция fn_BuiltinFunctionsExamples демонстрирует встроенные функции SQL Server:

 GETDATE() — текущая дата и время.
 YEAR() — получение года.
 UPPER() и LOWER() — изменение регистра текста.
 LEN() — длина строки.
 ROUND() — округление числа.
 ABS() — модуль числа.
 ISNULL() — замена значения NULL.
 CONCAT() — объединение строк.
 DATEADD() — изменение даты.

Файл с кодом: function.sql

2. Хранимая процедура

Процедура usp_StudentDifference подсчитывает количество поступивших и выпустившихся студентов за указанный год и рассчитывает разницу между ними.

Файл с кодом: procedure.sql

Результат

Функция выводит примеры работы встроенных функций SQL Server. Процедура показывает количество поступивших, количество выпускников и разницу между ними.
