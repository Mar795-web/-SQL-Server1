Представления в SQL Server
Цель работы
Создать три представления в базе данных BSTU и проверить их работу.
View_Auditorium
Представление выводит информацию об аудиториях: номер, тип и вместимость.
Это представление является изменяемым. Через него можно изменять данные основной таблицы AUDITORIUM.
View_Teachers
Представление выводит информацию о преподавателях: имя, пол, кафедру и дату рождения.
View_AuditoriumCount
Представление показывает количество аудиторий каждого типа. Для подсчёта используется функция COUNT() и группировка GROUP BY.
Результат
Созданы три представления. Выполнены запросы для проверки результатов. Одно из представлений позволяет изменять данные основной таблицы.
